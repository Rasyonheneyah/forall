# 💡 ForAll, a Vitrine Acadêmica (Fórum de Projetos)

Um fórum simples e direto para compartilhar soluções inovadoras e projetos criados dentro da faculdade. Desenvolvido para o Hackathon, este espaço serve para conectar alunos de diferentes cursos e dar visibilidade às ideias que nascem no meio acadêmico.

## 🎯 Qual é o objetivo?
Muitas ideias geniais ficam presas em trabalhos de fim de semestre ou morrem depois de um evento. Este fórum existe para:
* Compartilhar os projetos desenvolvidos durante o Hackathon.
* Expor trabalhos de destaque da própria faculdade.
* Conectar alunos de diferentes áreas (não é só para a galera de TI!).

## 🚀 Como funciona?
A ideia é ser acessível. Qualquer aluno pode publicar seu projeto rapidamente:
1. Adicione o nome do projeto.
2. Escreva uma breve descrição (Qual problema ele resolve?).
3. Compartilhe com a comunidade acadêmica para trocar ideias e receber feedbacks!
